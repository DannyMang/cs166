# Phishing Detection Project

A comprehensive project for simulating phishing attacks and developing countermeasures using machine learning.

## Project Overview

This project consists of three main components:

1. **Browser Extension**: A Chrome extension that uses machine learning to detect and prevent phishing attempts in real-time.
2. **Machine Learning Model**: A model trained to identify phishing patterns in URLs and webpage content.
3. **Phishing Simulator**: A tool for creating and sending simulated phishing emails for educational purposes.

## Getting Started

### Prerequisites

- Python 3.8+
- TensorFlow 2.x
- Node.js (for browser extension development)
- Chrome browser (for testing the extension)
